# Macchinetta IG

Progetto di trading automatico / simulatore per la piattaforma IG.

## File principali
- `Motore.py`: Motore principale dell'applicazione.
- `Dashboard.py`: Interfaccia grafica / dashboard.
- `Simulatore.py`: Simulatore delle strategie.
- `Backtester.py`: Backtesting delle strategie.
