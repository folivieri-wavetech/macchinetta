# CASSAFORTE HYPER M5 KJ (Kijun-sen 55)

Questo archivio contiene la versione esatta, funzionante e certificata del motore **Hyper M5 con Kijun-sen 55**, congelata prima dello sviluppo del nuovo motore alternativo.

## File archiviati:
- `hyper_gold_m5_engine.py`: Motore Hyper M5 per Spot Gold (Core 6 contratti + Incrementi Bancomat/Runner + Trailing Stop M5 + S&R KJ55)
- `hyper_us500_m5_engine.py`: Motore Hyper M5 per US 500 Cash (Core 6 contratti + Incrementi Bancomat/Runner + Trailing Stop M5 + S&R KJ55)
- `hyper_order_manager.py`: Gestore ordini Hyper, incrementi, trailing stop e chiusure
- `hyper_tab.py`: Tab interfaccia grafica Streamlit Hyper Scalping

## Come riesumare questa versione:
Per ripristinare all'istante questi file al posto di quelli attivi, l'utente scriverà semplicemente:
**`RIPRISTINA HYPER KJ`**
