# Regola di Formattazione: MAI Sintassi LaTeX né Formule con Dollaro ($)

Nelle risposte all'utente:
1. **DIVIETO ASSOLUTO DI SINTASSI LATEX E FORMULE CON DOLLARI `$`**:
   - Non usare MAI `$ ... $` o `$$ ... $$` per alcuna formula, espressione matematica o freccia.
   - NO: `$\text{Close} < \text{Kijun}$`
   - NO: `$\text{Close} > \text{Kijun}$`
   - NO: `$\text{Close} - 40\text{ pip}$`
   - NO: `$\ge 40\text{ pip}$`
   - NO: `$\pm 5\text{ pip}$`
   - NO: `$\rightarrow$`

2. **USA ESCLUSIVAMENTE TESTO SEMPLICE O GRASSETTO / CODICE INLINE**:
   - SI: `Close < Kijun` oppure **Close < Kijun**
   - SI: `Close > Kijun` oppure **Close > Kijun**
   - SI: `Close - 40 pip` oppure `Close + 40 pip`
   - SI: `>= 40 pip` oppure `<= 20 pip`
   - SI: `+/- 5 pip`
   - SI: `->` oppure `➡️`
